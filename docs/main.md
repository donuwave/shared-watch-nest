# Сервис совместного просмотра фильмов

## Цель

Создать сервис для совместного онлайн-просмотра фильмов. 
Пользователь вставляет прямую ссылку на видео, создаёт комнату и приглашает друзей. 
Все участники синхронно смотрят фильм, общаются голосом и в текстовом чате, а также настраивают громкость 
фильма и собеседников.

---

# Функционал

## Главная страница

- Создание комнаты.
- Вставка прямой ссылки на фильм.
- Указание имени пользователя.
- Получение и копирование ссылки-приглашения.
- Вход в существующую комнату по ссылке.

---

## Дизайн и цветовая тема

### Общий стиль

- Интерфейс должен ощущаться как полноэкранный кинозал, а не как обычная панель управления.
- Основной экран комнаты строится вокруг видео на всю ширину и высоту окна.
- Панели, плеер, чат и кнопки отображаются поверх видео как полупрозрачные overlay-элементы.
- Дизайн должен быть тёмным, контрастным, спокойным и удобным для просмотра фильма в темноте.
- Главные акценты: синхронизация, активный микрофон, владелец комнаты, опасные действия.

### Базовая палитра

| Назначение | Токен | Цвет |
| --- | --- | --- |
| Основной фон | `--color-bg` | `#06080D` |
| Вторичный фон | `--color-surface` | `#10141C` |
| Overlay поверх видео | `--color-overlay` | `rgba(9, 12, 18, 0.72)` |
| Слабый overlay | `--color-overlay-soft` | `rgba(9, 12, 18, 0.42)` |
| Граница overlay | `--color-border` | `rgba(255, 255, 255, 0.12)` |
| Основной текст | `--color-text` | `#F4F7FA` |
| Вторичный текст | `--color-text-muted` | `#AAB3C2` |
| Слабый текст | `--color-text-subtle` | `#6F7A8A` |
| Главный акцент | `--color-accent` | `#22D3C5` |
| Акцент при наведении | `--color-accent-hover` | `#5EEADF` |
| Активное состояние | `--color-active` | `#2AF598` |
| Владелец комнаты | `--color-owner` | `#F5B84B` |
| Микрофон выключен | `--color-muted` | `#F05252` |
| Опасное действие | `--color-danger` | `#EF4444` |
| Предупреждение | `--color-warning` | `#F59E0B` |
| Успех | `--color-success` | `#22C55E` |

### Цвета интерфейсных состояний

- Синхронизация видео: `--color-accent`.
- Участник говорит: кольцо вокруг аватарки `--color-active`.
- Микрофон включён: маленький индикатор `--color-accent`.
- Микрофон выключен: индикатор `--color-muted`.
- Владелец комнаты: маленький бейдж `--color-owner`.
- Удаление участника или сообщения: `--color-danger`.
- Закрытый вход в комнату: `--color-warning`.

### Кастомизация темы

- Все цвета должны использоваться через CSS-переменные или дизайн-токены, а не напрямую в компонентах.
- Компоненты не должны знать конкретные hex-цвета; они должны использовать семантические токены.
- В будущем можно добавить несколько тем:
  - стандартная тёмная;
  - светлая;
  - AMOLED;
  - пользовательская тема комнаты;
  - тема профиля пользователя.
- Настройки темы должны храниться отдельно от логики комнаты.
- Минимальная модель темы:

```ts
type AppTheme = {
  id: string
  name: string
  colors: {
    bg: string
    surface: string
    overlay: string
    overlaySoft: string
    border: string
    text: string
    textMuted: string
    textSubtle: string
    accent: string
    accentHover: string
    active: string
    owner: string
    muted: string
    danger: string
    warning: string
    success: string
  }
}
```

## Комната

### Видеоплеер

- Общий видеоплеер.
- Синхронный запуск фильма.
- Синхронная пауза фильма.
- Синхронная перемотка фильма.

### Голосовое общение

- Голосовое общение между участниками.
- Включение своего микрофона.
- Отключение своего микрофона.
- Настройка громкости фильма.
- Отдельная настройка громкости каждого участника.

### Участники

- Список участников.
- Индикатор говорящего участника.
- Копирование ссылки на комнату.
- Выход из комнаты.

---

## Текстовый чат

- Отправка сообщений.
- Отображение автора сообщения.
- Отображение времени отправки.
- Редактирование собственных сообщений.
- Удаление собственных сообщений.
- Удаление сообщений владельцем комнаты.
- Отметка об изменении сообщения после редактирования.
- Синхронное обновление чата у всех участников.

---

## Управление комнатой

### Права владельца

- Создатель комнаты становится владельцем.
- Владелец управляет воспроизведением фильма.
- Владелец может выдавать право управления фильмом.
- Владелец может отзывать право управления фильмом.
- Несколько участников могут одновременно иметь право управления.

### Управление участниками

- Отключение микрофонов участников.
- Удаление участников из комнаты.

### Доступ в комнату

- Открытие и закрытие входа в комнату переключателем.
- При закрытом входе новые участники не могут присоединиться даже по действующей ссылке.
- Участники, уже находящиеся в комнате, продолжают просмотр.

# Технические возможности

## Видео

- Воспроизведение фильма по прямой ссылке без загрузки на сервер.
- Синхронизация видеоплеера в реальном времени.
- Подключение нового участника к текущему моменту просмотра.
- Автоматическое восстановление после потери соединения.
- Отображение ошибки при неподдерживаемой ссылке или формате видео.
- На стоп кадре давать возможность пользователям что-то рисовать

## Голосовая связь

- Голосовая связь в реальном времени.
- Персональная настройка громкости каждого участника.

## Текстовый чат

- Работа в реальном времени.
- Хранение сообщений в рамках комнаты.
- Синхронизация новых сообщений.
- Синхронизация изменений сообщений.
- Синхронизация удаления сообщений.
- Если приходит новое сообщение, то выводить сообщение ghost снизу, чтоб не лезть в чат каждый раз

## Серверная логика

- Проверка прав на управление комнатой.
- Проверка прав на управление фильмом.
- Проверка прав на редактирование сообщений.
- Проверка прав на удаление сообщений.
- Проверка состояния переключателя входа в комнату.

## Жизненный цикл комнаты

- Автоматическое удаление временной комнаты после выхода всех участников.
